# 🌟 Rewply AI - The Ultimate Review Triage & Growth Engine

![Next.js](https://img.shields.io/badge/Next.js-14-black?style=for-the-badge&logo=next.js) ![AI Integration](https://img.shields.io/badge/Gemini_AI-Powered-blue?style=for-the-badge)

## 📖 The Problem
Small businesses receive reviews across multiple platforms (Google, Yelp, Trustpilot), but owners lack the time to monitor every review and respond appropriately. Negative reviews remain unanswered for days, causing permanent brand damage, while positive reviews are ignored, missing marketing opportunities.

## 🚀 The Solution: Rewply AI
Rewply AI is an intelligent agent that automatically monitors customer reviews, categorizes sentiment, identifies urgent complaints, drafts personalized responses, and turns positive/resolved reviews into viral LinkedIn marketing content.

---

## ✨ Key Features

### 1. Intelligent Problem Triage
- **Centralized Dashboard:** Ingests reviews and categorizes them by urgency.
- **Operational Focus:** The `AI Action Center` translates negative reviews into actionable tickets (e.g., "Undercooked Meat" is automatically flagged as a CRITICAL kitchen alert).

### 2. Premium UX & Design
- **Modern Interface:** Beautiful, fully responsive UI built with Tailwind CSS, supporting dark mode and glassmorphism.
- **Action-Oriented Workflows:** Pulsing alerts for critical issues, smooth modal animations, and detailed empty states provide a polished, SaaS-ready experience.

### 3. Contextual AI Responses
- **Gemini Powered:** Integrated `@google/generative-ai` to power dynamic review responses.
- **Smart Drafting:** AI dynamically adjusts tone (Empathetic, Professional, Grateful) based on the customer's sentiment, allowing businesses to respond perfectly in seconds.

### 4. LinkedIn Marketing Engine
- **Viral Growth:** The `LinkedInBoast` component converts customer feedback into high-engagement LinkedIn posts.
- **Multiple Narratives:** Generate posts for "Customer Spotlight", "Turnaround Story", "Team Milestone", or "Thought Leadership".
- **Realistic Previews:** A stunning, interactive mockup of the LinkedIn feed right in the dashboard.

---

## 💻 Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS & Lucide Icons
- **AI Engine:** Google Gemini (`@google/generative-ai`)
- **Database/Auth:** Supabase

## 🛠️ Getting Started

First, install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
